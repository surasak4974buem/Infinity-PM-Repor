CH9102DS1.PDF
เอกสารข้อมูล CH9102, ชิป USB ต่อพอร์ตอนุกรมเดียว รองรับอัตราบอดสูงสุด 4M พอร์ตอนุกรม CH9102F รองรับสัญญาณ 1.8-5V, มีการควบคุมทิศทาง RS485 และพินสัญญาณ GPIO และมีคริสตัลออสซิลเลเตอร์ในตัว มีให้เลือกทั้งแบบแพ็คเกจ QFN24 และ QFN28 CH9102 ใช้ไดรเวอร์ CDC ในตัวของระบบหรือไดรเวอร์ของผู้ผลิต ไดรเวอร์ของผู้ผลิตรองรับฟังก์ชันพอร์ตอนุกรมเต็มรูปแบบและอัตราบอดที่สูงกว่า
CH343SER.EXE
ไดรเวอร์พอร์ตอนุกรม USB-to-highspeed นี้เป็นไดรเวอร์ที่ติดตั้งโดยผู้ผลิต Windows ในคลิกเดียว รองรับ CH342/CH343/CH344/CH346/CH347/CH9101/CH9102/CH9103/CH9104/CH9111/CH9114/CH9143 และ Windows 11/10/8.1/8/7/VISTA/XP/2000 แบบ 32/64 บิต และ Server 2022/2019/2016/2012/2008/2003 ไดรเวอร์นี้ได้รับการรับรองและลงนามดิจิทัลจาก Microsoft และรองรับพอร์ตอนุกรม USB-to-UART/3 สาย และ 9 สาย ไดรเวอร์ VCP จากผู้ผลิตมอบชุดคุณสมบัติที่ครอบคลุมยิ่งขึ้น รวมถึงพอร์ตอนุกรมที่มีคุณสมบัติครบถ้วน การควบคุมการไหลของฮาร์ดแวร์ GPIO การกำหนดค่าพารามิเตอร์ USB และการส่งข้อมูลที่เสถียรและเสถียรที่อัตราบอดสูง มีวัตถุประสงค์เพื่อการจัดจำหน่ายให้กับผู้ใช้ปลายทางพร้อมกับผลิตภัณฑ์
CH343SER.ZIP
ไดรเวอร์ USB ต่อพอร์ตซีเรียลความเร็วสูงจากผู้ผลิต Windows และไฟล์ไลบรารี LIB รองรับ CH342/CH343/CH344/CH346/CH347/CH9101/CH9102/CH9103/CH9104/CH9111/CH9114/CH9143 และรองรับ Windows 11/10/8.1/8/7/VISTA/XP/2000, SERVER 2022/2019/2016/2012/2008/2003 แบบ 32/64 บิต ไดรเวอร์นี้ได้รับการรับรองด้วยลายเซ็นดิจิทัลจาก Microsoft รองรับพอร์ตซีเรียล USB ต่อ UART/3 สาย และ 9 สาย ไดรเวอร์ VCP จากผู้ผลิตมีฟังก์ชันที่ครบถ้วนยิ่งขึ้น รวมถึงพอร์ตซีเรียลที่ใช้งานได้เต็มรูปแบบ การควบคุมการไหลของฮาร์ดแวร์ GPIO การกำหนดค่าพารามิเตอร์ USB และการส่งข้อมูลอย่างต่อเนื่องและเสถียรที่อัตราบอดสูง
CH343CDC.EXE
ไดรเวอร์ติดตั้งพอร์ตอนุกรม USB-to-CDC สำหรับ Windows แบบคลิกเดียวนี้รองรับ CH342/CH343/CH344/CH91XX/WCHLinkSER และ Windows 2000/XP/Vista/7/8/8.1/10/11/SERVER 2003/2008/2012/2016/2019/2022 แบบ 32/64 บิต ไดรเวอร์นี้ได้รับการรับรองและลงนามโดย Microsoft แบบดิจิทัล และรองรับ CH342/CH343/CH344/CH347/CH910X/CH9143/CH9340/WCHLinkSER รวมถึงพอร์ตอนุกรม USB 3 สายและ 9 สาย ไดรเวอร์นี้มีไว้สำหรับแจกจ่ายให้กับผู้ใช้ปลายทางพร้อมกับผลิตภัณฑ์
CH343CDC.ZIP

CH9101DS1.PDF
คู่มือทางเทคนิค CH9101, ชิป USB ต่อพอร์ตอนุกรมเดียว รองรับอัตราบอดสูงสุด 3M พอร์ตอนุกรม CH9101 รองรับ 5V/3.3V/2.5V/1.8V มีการควบคุมทิศทาง RS485 และพินสัญญาณ GPIO รองรับการควบคุมการไหลของข้อมูลฮาร์ดแวร์ และมีออสซิลเลเตอร์คริสตัลในตัว มีให้เลือกในแพ็คเกจ SSOP28, QFN32, QFN16 และ QSOP16 CH9101 ใช้ไดรเวอร์ CDC ที่รวมอยู่ในระบบหรือไดรเวอร์ของผู้ผลิต ไดรเวอร์ของผู้ผลิตรองรับฟังก์ชันพอร์ตอนุกรมเต็มรูปแบบและอัตราบอดที่สูงกว่า
CH347DS1.PDF
